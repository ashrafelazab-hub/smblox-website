# smblox-website

The public website for SMBlox, served at https://smblox.com by GitHub Pages.

- Static files only: `index.html`, `privacy.html`, `404.html`, `style.css`, `assets/`.
- Brand rules come from the SMBlox brand file (company/02 F). Fonts are Space Grotesk and Inter, both under the SIL Open Font License (`assets/fonts/OFL-*.txt`).
- This repo is public. Never commit secrets, client data or drafts.
- Changes ship only after the founder approves them.
